## Summary

RoguePlanet is a local privilege escalation exploit for Windows 10 and 11 that abuses a race condition in Windows Defender's scan pipeline. The exploit mounts an attacker-controlled ISO image via the VirtualDisk API, plants an EICAR-like trigger file inside it, and races Defender's file-open handle against a directory junction swap while simultaneously driving the WER `QueueReporting` Task Scheduler task to execute as SYSTEM. If the race is won, the attacker's payload runs in the SYSTEM context. The exploit is non-deterministic (race-dependent) but achieves high success rates on tested builds.

---

## Vulnerability Details

### Root Cause

Windows Defender opens scan targets using shared file handles and resolves paths at scan time without holding exclusive locks across the entire scan-to-action pipeline. A TOCTOU window exists between when Defender opens the EICAR-triggered file path and when it acts on it. Combined with directory junction swaps and reparse point manipulation, an attacker can redirect Defender's file handle into a privileged execution context backed by the WER `QueueReporting` scheduled task (running as SYSTEM under `\Microsoft\Windows\Windows Error Reporting`).

### Attack Vector

1. Mount a crafted ISO image using `OpenVirtualDisk` / `AttachVirtualDisk` (no admin required on Windows 10/11 for standard users).
2. Write an EICAR-compatible trigger file into a working directory, triggering a Defender scan (`WDStartScan`).
3. Race a directory junction swap (`NtSetInformationFile` rename + reparse point replacement) against Defender's handle acquisition.
4. Simultaneously connect to Task Scheduler and trigger the WER `QueueReporting` task (`\Microsoft\Windows\Windows Error Reporting\QueueReporting`).
5. If the race succeeds, `wermgr.exe` path resolution is hijacked and the attacker's payload is executed as SYSTEM.

### Impact

Full local privilege escalation to SYSTEM on Windows 10/11 for any standard (non-admin) local user. Windows Server is also theoretically vulnerable but requires a redesigned PoC (standard users cannot mount ISOs on Server).

## Proof of Concept

### Step-by-Step Reproduction

1. **Copy `RoguePlanet.exe`** (or compile from source) to the target machine as a standard user.
2. **Run `RoguePlanet.exe`** from a command prompt.
3. The exploit races Defender scan + junction swap. On success a SYSTEM shell spawns.
4. Verify: `whoami` → `nt authority\system`.

## Detection & Indicators of Compromise

```
Get-WinEvent -LogName System | Where-Object {$_.Id -eq 7045 -or $_.Message -like "*VirtualDisk*"}

auditpol /set /subcategory:"File System" /success:enable
Get-WinEvent -LogName "Microsoft-Windows-TaskScheduler/Operational" |
  Where-Object {$_.Message -like "*QueueReporting*"}

Get-WinEvent -LogName Security | Where-Object {$_.Id -eq 4688 -and $_.Message -like "*wermgr*"}
```

**YARA (memory/on-disk):**
```
rule RoguePlanet_LPE {
  strings:
    $pipe = "\\\\.\\pipe\\RoguePlanet" wide
    $task = "QueueReporting" wide
    $wer  = "Windows Error Reporting" wide
    $eicar_fn = "wermgr.exe" wide
  condition:
    3 of them
}
```

## Remediation

| Action | Detail |
|---|---|
| **Patch** | No CVE or official patch announced at time of ingest; report to MSRC |
| **Workaround** | Restrict standard users from mounting ISO images via Group Policy (`User Configuration → Administrative Templates → Windows Components → File Explorer → Prevent users from mounting ISO/IMG files`) |
| **Config Hardening** | Disable or restrict the WER `QueueReporting` scheduled task for non-essential endpoints; enable Defender tamper protection and ASR rules |
